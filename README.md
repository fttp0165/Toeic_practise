# TOEIC 衝刺計畫 · 海馬迴單字庫

個人用的 TOEIC 衝刺工具，核心是**海馬迴間隔複習單字法**。目標分數 **300 → 500**，重點在「撿回該拿沒拿的分」。

**設定你的目標日**（例如報考日 12/20），系統自動從今天倒數，並把五階段、每日任務、間隔複習與日期條**縮放到那段天數**——不再固定 20 天，可規劃任意長度、也能同時保存多份計畫。

純靜態網頁（原生 HTML/CSS/JS，無框架、無建置流程），可直接用瀏覽器開啟，部署在 GitHub Pages。

🔗 **線上版**：<https://fttp0165.github.io/Toeic_practise/>

---

## 兩個頁面

| 頁面 | 網址 | 用途 |
|---|---|---|
| **衝刺計畫** | `index.html`（首頁） | 可設定目標日的倒數衝刺：選考試/目標日自動倒數並縮放整份計畫（五階段、每日任務、間隔複習、日期條）；可建立/切換多個專案 |
| **海馬迴單字庫** | `library.html` | 不限天數的長期單字庫：依**真實日期**排間隔複習、隨時新增與翻卡練習 |

兩頁頂部導覽列互相連結，**共用同一池單字**（同一份 `localStorage`，登入後同步同一份雲端資料），但複習排程各自獨立。

## 核心方法：海馬迴間隔複習

1. **輸出 > 輸入**：蓋住中文、考自己，想不出來才翻開（主動回想本身就是記憶訊號）。
2. **間隔複習**：每批單字在 **+1 / +3 / +7 / +14 天**被重新喚起。
3. **睡眠固化**：新字排睡前、起床先回想，別熬夜。
4. **連結 + 情緒**：把新字連到已知的事物。

> ⚠️ 「先回想、再翻開驗證」是整個工具的靈魂，所有翻卡都遵循此設計，不可改成被動瀏覽。

## 功能總覽

### 衝刺計畫頁
- **衝刺專案（可設定目標日）**：選一個考試/目標日（例如 12/20），系統自動從今天倒數，並把整份計畫縮放到那段天數；也可手動設開始日規劃任意區間。顯示「距離考試還有 N 天」。
- **多專案**：可建立／切換／重新命名／刪除多個具名專案（例如「3 月正式考」「12 月加考」），各專案的日期與打勾互相獨立。
- **五階段自動縮放**：階段邊界依總天數按比例（15/30/25/20/10%）自動分配，短長計畫都合理；`days=20` 與舊版完全一致。
- **日期選擇條**：顯示「共 N 天」，每天完成度、今天標示，可點選查看任一天。
- **間隔複習區（核心）**：自動列出今天到期的舊批次，攤成翻卡（英文＋例句先顯示、中文模糊）。
- **每日任務清單**：依五階段帶具體練習量，可打勾、狀態持久化。
- **每日單字輸入**：單字 / 中文 / 例句 / 備註；同一字跨全表去重，重複輸入只補例句。
- **進度總覽**：完成率、連續天數、完成度方格圖（格數＝總天數）。
- **單字池永不清空**：刪除專案／清除進度只動該專案的日期與打勾，單字與學習進度一律保留、持續累積。

### 海馬迴單字庫頁
- **共用單字池**：20 天輸入的字（標「第 N 批」）與單字庫新增的字（標「單字庫」）同在一處。
- **依真實日期的個人 SRS**：把字選為「今天新學」後，依 +1/+3/+7/+14 真實天數自動排複習。
- **今天要複習**：到期單字以翻卡呈現，翻開後選「記得 ✓（進下一階）/ 忘了 ✕（重排）」。
- **新增單字**：直接加進單字庫並開始學習。
- **全部單字**：可搜尋（單字／中文／例句／備註）、編輯、刪除，每筆顯示學習狀態徽章。

### 共用
- **編輯 / 刪除單字**：兩頁皆可就地編輯（含多例句，一行一句）。
- **雲端同步（選用）**：用 Google 一鍵登入後，進度與單字自動同步到 Firebase，換裝置不怕。未登入時資料只存在本機瀏覽器。

## 專案結構

```
Toeic_practise/
├── index.html          # 20 天衝刺頁（GitHub Pages 首頁）
├── library.html        # 海馬迴單字庫頁
├── styles.css          # 共用樣式
├── app-core.js         # 共用主邏輯：狀態 / 間隔複習引擎 / 單字 helpers / 各區渲染
├── sync.js             # 共用 Firebase 同步層（ES module）
└── Docs/
    ├── PROJECT_PLAN.md   # 完整規劃書（邏輯規格、資料模型、藍圖）
    └── FIREBASE_SETUP.md # Firebase 雲端同步設定步驟
```

設計重點：
- **一份 `app-core.js` 服務兩頁**——每個渲染函式只在對應容器存在時動作，所以同一支腳本能同時跑兩個頁面、無重複。
- **`window.TOEIC` 橋接**——`app-core.js` 暴露 `getLocal / applyRemote / isLocalEmpty / setOnChange`，`sync.js` 只依賴這個介面；將來換後端只需改 `sync.js`。

## 資料儲存

未登入時存在瀏覽器 `localStorage`：

| key | 內容 |
|---|---|
| `toeic20_projects` | 衝刺專案清單：`[{ id, name, start, exam, days, tasks }]`（`exam`＝考試/目標日，`days`＝總天數，`tasks`＝該專案打勾狀態）。隨雲端同步 |
| `toeic20_curproj` | 目前開啟的專案 id |
| `toeic20_start` | （相容）舊版單一開始日 `YYYY-MM-DD`；已改由各專案的 `start` 保存，僅作遷移相容 |
| `toeic20_tasks` | （相容）舊版已完成任務；已改由各專案的 `tasks` 保存 |
| `toeic20_vocab` | 單字：`{ "{批次}": [ { w, m, exs[], n, lo?, ri? } ] }`。`lo`/`ri` 為單字庫的學習日期與複習階段；非數字鍵 `lib` 為單字庫專屬桶 |

登入後同步到 **Firebase Realtime Database**（`users/{uid}`，免費 Spark 方案、不綁卡）。設定步驟見 [Docs/FIREBASE_SETUP.md](Docs/FIREBASE_SETUP.md)。

## 匯入檔格式

單字庫頁 →「匯入 CSV／JSON」。**依副檔名判斷**：`.json` 走 JSON，其餘一律當 CSV。

### CSV

建議直接沿用「匯出 CSV」的標題列（匯出檔帶 BOM，Excel 開中文不亂碼）：

```csv
word,meaning,pos,example,example_zh,note
agenda,議程,n.,Send the agenda.,寄出議程。,CH8
invoice,發票,n.,"Please attach the invoice, thanks.",請附上發票，謝謝。,
```

- **有沒有標題列都可以。** 判定為標題列的條件：第一欄是 `word`／`單字`，或任一欄含 `meaning`／`中文`／`example`／`例句`。
- **沒有標題列**時固定吃 4 欄：`word, meaning, example, note`。
- 有標題列時依欄名對應（不分大小寫，順序不拘）：

  | 欄位 | 可用的欄名 |
  |---|---|
  | 單字 | `word`、含「單字」 |
  | 中文 | `meaning`、含「中文」或「意思」 |
  | 詞性 | `pos`、含「詞性」、`part...speech` |
  | 例句 | `example` 或 `例句`（需完全相符） |
  | 例句翻譯 | 含 `example_zh`／`例句中文`／`例句翻譯`／`翻譯` |
  | 備註 | `note`、含「備註」；若有例句翻譯欄卻沒有備註欄，第 5 欄視為備註 |

- **多個例句用 `|` 分隔**，`example_zh` 依相同順序一一對應。
- 值裡有逗號、雙引號或換行時用雙引號包起來；內部的雙引號寫成 `""`（標準 CSV）。
- 單字欄空白的列會略過。

### JSON

兩種都收，程式自動判斷：

**1. 完整備份檔**（本站「匯出 JSON」產生）— 物件且有 `_app:"toeic20"`，**或**有 `vocab` 物件。

```json
{ "_app":"toeic20", "_v":2, "start":"", "tasks":{},
  "vocab":{ "lib":[{ "w":"invoice","m":"發票","exs":[{"e":"...","t":"..."}] }] },
  "log":{}, "libs":["我的單字庫"], "curlib":"我的單字庫",
  "projects":[], "curproj":"" }
```

匯入時會**先問你**要「只新增單字（不動現有資料）」還是「整包還原（覆蓋現有資料）」，選擇前不會更動任何資料。
若 `_app` 存在但不是 `toeic20`，直接拒絕。

**2. 單字清單** — 陣列，或物件包一層 `{ words | vocab | list | data | items: [...] }`：

```json
[ { "word":"agenda", "meaning":"議程", "pos":"n.",
    "example":"Send the agenda.", "example_zh":"寄出議程。", "note":"CH8" } ]
```

欄位別名（擇一即可）：

| 欄位 | 可用的鍵 |
|---|---|
| 單字 | `w`、`word`、`單字`、`英文`、`term`（**必填**，空的略過） |
| 中文 | `m`、`meaning`、`中文`、`意思`、`translation`、`定義` |
| 詞性 | `p`、`pos`、`詞性`、`part_of_speech` |
| 備註 | `n`、`note`、`備註`、`筆記` |
| 例句 | `exs`：`[{e,t}]` 或字串陣列；沒有 `exs` 時用 `example`／`ex`／`例句`／`sentence`，翻譯用 `example_zh`／`例句中文`／`例句翻譯`／`翻譯` |

單字清單一律「**新增合併**」進目前單字庫，不會覆蓋既有資料。

### 共同規則

- **去重**：與**目前選取的單字庫**內的同名字比對（去除前後空白、不分大小寫）。命中時只**補上缺的**中文／詞性／備註，並附加尚未存在的例句——**不覆蓋**你已經填好的內容。
- **新字寫入**：`lib` 設為目前單字庫，`da`（加入日期）設為今天。備份檔選「只新增單字」時，會保留原本的 `da` 與學習進度 `lo`／`ri`。
- **結果訊息**會顯示新增／更新了幾字。失敗時的訊息：`JSON 格式錯誤`、`不是有效的備份檔`、`不是備份檔，也不是單字清單`。
